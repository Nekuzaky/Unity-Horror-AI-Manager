# Horror AI Manager

Enemy AI for horror games. Enemies see with a view cone and a suspicion gauge that fills slowly in the dark and fast
in the light, hear noises through walls, remember where you were, and patrol, investigate, search and chase you with
a deterministic state machine. Events for every scare, plain-word inspectors with one-click fixes, Scene view gizmos,
a live debug window, and zero garbage per frame.

- Install: **Window > Package Manager > + > Install package from git URL...**
  `https://github.com/Nekuzaky/Unity-Horror-AI-Manager.git?path=/Packages/com.nekuzaky.horror-ai-manager`
- Start: **GameObject > Horror AI > Enemy**, then follow its inspector.
- Watch: **Window > Horror AI**.
- Try: the **Greybox Demo** sample.
