# Security Policy

Horror AI Manager is a runtime library for your game. It makes no network request, reads and writes no file, and
only runs the perception and behavior code of the enemies you place in your scenes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private
[security advisory form](https://github.com/Nekuzaky/Unity-Horror-AI-Manager/security/advisories/new) instead, with
steps to reproduce. You should get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
